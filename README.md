# Product Recommendation System

This is a Machine Learning based Product Recommendation System built using Python, NLP, TF-IDF, and Cosine Similarity.

## Live Demo

https://saniya3540-recommendation-system.streamlit.app/

## Features

* Product recommendation
* NLP text preprocessing
* TF-IDF Vectorization
* Cosine Similarity
* Streamlit Web App

## Technologies Used

* Python
* Pandas
* Scikit-learn
* NLTK
* Streamlit

The dataset was not uploaded because of large file size.
